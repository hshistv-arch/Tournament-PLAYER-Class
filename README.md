# Tournament PLAYER-Class

ビリヤード大会のクラスポイントを管理するツールです。勝敗ポイント表（クラスの組み合わせごとに勝者が得る点・敗者が失う点を定めた表）に基づいて、試合結果からクラスポイントを自動計算・更新します。

## 使い方

https://tournament-player-class.vercel.app を開くだけで使えます。ログイン不要で、このURLを知っている人は誰でも同じデータ(選手ロースター・大会結果など)を見て編集できる「共有ノート」のような仕組みです。`index.html` をファイルとして直接ブラウザで開くこともできますが、その場合は後述のクラウド同期は行われず、その端末のみに保存されます。スマートフォンでは「ホーム画面に追加」でアプリのように起動でき、アイコンには G-SPeC の大会写真を使用しています。

## 主な機能

- **選手ロースター**: 選手の追加、氏名・読みカナ・ポイントをその場で編集、削除。クラス(SA〜CC)はポイントから自動判定。一覧は「ポイント順」「名前順」を切り替えて表示可能(名前順は読みカナがあればそれを、なければ氏名を使用)。ポイント欄の左には、その選手が参加した直近の完了済み大会より前の「前回ポイント」も参考表示されます。選手一覧はCSVファイルとして書き出し可能(表示中の並び順で出力)、または「サマリーを印刷」から氏名・クラス・最新ポイントのみの印刷用一覧(名前順)を表示して印刷できます
- **エントリー受付**: 大会作成前に、出場選手のエントリーと参加費受領を選手ごとにチェック(名前順で表示)。大会作成後の組み合わせ選択は、ここでエントリー・受領済みの選手が対象になります(未設定の場合はロースター全員が対象)
- **大会作成**: 大会名を入力したら、まず「出場選手を選択」欄でエントリー・参加費受領済みの選手一覧(名前順)からチェックボックスで出場者を選びます(デフォルトで全員チェック済み・欠席者はチェックを外すだけ)。総参加人数はチェック数から自動設定され、続けて試合形式を選ぶだけで完了です
  - **①トーナメント戦(予選+決勝)**: 予選をシングルエリミネーション(1敗失格)またはダブルエリミネーション(2敗失格・敗者復活あり)のノックアウト方式で行い、予選グループ数・各グループからの決勝進出人数を指定。指定人数まで絞り込まれたら決勝トーナメントへ
  - **②予選リーグ戦(ブロック総当たり)+決勝トーナメント**: 参加者をブロックに分けて総当たり戦を行い、各ブロック上位が決勝トーナメントに進出(ブロック内で2敗した選手は自動的に予選敗退)
- **大会作成時に出場選手を自動割当**: 「出場選手を選択」でチェックした選手は、大会作成と同時にポイント順のシードで各グループ/ブロックの枠へ自動的に割り当てられます(グループが複数ある場合は上位選手が均等に分散されます)。作成後も「出場選手を編集」欄のプルダウンでいつでも組み替え可能です(「組み合わせを確定」で大会を開始。未割当の枠は不戦/空きとして扱われます)。出場選手は決勝トーナメント開始後・大会終了後でも入れ替え可能で、変更すると該当ブロック/グループの結果と決勝トーナメントの結果が自動的に巻き戻されて再構築されます。決勝トーナメントの枠(空の「(不戦)」表示)も、予選が確定する前から進出予定人数分だけ先に表示されます
- **開始後の人数・決勝進出人数の変更**: 各ブロック/グループの人数と、各ブロック/グループからの決勝進出人数は、大会開始後・決勝トーナメント開始後でもいつでも変更可能です(変更すると該当ブラケット・決勝トーナメントの結果が必要に応じて巻き戻されます)。ダブルエリミネーションの場合、決勝進出人数は勝者側・敗者側それぞれ何名ずつ選出するかを個別に指定できます(各グループの現在の勝ち残り上位からポイント順に選出)
- **トーナメント表ビジュアル**: 決勝トーナメントおよび予選のシングル/ダブルエリミネーションを、対戦カードを線でつないだブラケット表示で見える化(対戦Noを表示。ダブルエリミネーションの敗者復活ブロックは別枠でリスト表示)。予選開始直後などまだ結果が出ていないラウンドも「(未定)」の空き枠として先に表示され、トーナメント表全体の形が常に見えるようになっています。予選の勝者側ブラケットは、設定した決勝進出人数まで絞り込むのに必要なラウンド数までしか表示されません(例: 8名中4名が決勝進出なら1回戦のみ、2名なら2回戦まで)。実際にはプレイされない先のラウンドの枠は表示されません
- **試合結果入力・スコア記録**: 勝者を選ぶだけでクラス組み合わせに応じたポイントが自動加減算。対戦スコアは選手名の横に記録可能(ポイント計算には影響しない参考記録)。結果は決勝トーナメント開始後・大会終了後でもいつでも取消・修正でき、後続の組み合わせ結果や決勝トーナメントの結果が既にある場合は自動的に巻き戻して再計算します
- **決勝トーナメント**: 優勝・準優勝が決まると、進出ボーナス・優勝ボーナス・ベストB/Cクラスボーナス・前回優勝者撃破ボーナスなどを自動計算して選手ポイントに反映し、次回大会用に優勝者を記録。決勝トーナメントの組み合わせは「ランダムに再抽選」または「決勝進出者の中から任意で組み合わせを選んで編集」のどちらでも変更可能です(進行中の対戦結果・大会結果があれば取り消してから組み直します)
- **大会終了時のポイント変化一覧**: 大会が終了すると、優勝・準優勝のボーナスログに加えて、その大会に参加した全選手の合計ポイント変動(対戦の勝敗・ボーナス・ペナルティをすべて合算、下限ポイントのルールも適用済み)と、その隣に最新の合計ポイントを一覧表示します。「大会結果を印刷する」から、優勝・準優勝・ボーナス内訳・決勝トーナメント表を印刷用にまとめて表示・印刷できます
- **対戦ごとのセット数・持ち時間**: 対戦カードに、両選手それぞれの必要セット数とチェスクロックの持ち時間を自動表示します(下記「対戦ルール」参照)。組み合わせが決まっている対戦であれば、予選・決勝を問わず表示されます
- **設定**: クラス区分の点数範囲、勝敗ポイント表(勝利時／敗北時)、各種ボーナス点数をすべて編集可能(デフォルトに戻すボタンあり)
- **データ管理**: JSONファイルへのエクスポート／インポートで端末間のデータ共有が可能
- **大会の削除**: 大会一覧から削除すると、その大会で加減算されたポイントがすべて元に戻ります

## クラス区分(初期値)

| クラス | 範囲 |
| --- | --- |
| SA | 100以上 |
| AA | 90〜99 |
| AB | 80〜89 |
| AC | 70〜79 |
| BA | 60〜69 |
| BB | 50〜59 |
| BC | 40〜49 |
| CA | 30〜39 |
| CB | 20〜29 |
| CC | 10〜19 |
| Be | 0〜9 |

## 対戦ルール(セット数・持ち時間・セカンダリハンデ)

各対戦カードには、両選手それぞれの必要セット数とチェスクロックの持ち時間が自動表示されます。

**クラスごとの基本セット数と持ち時間**

| クラス | セット数 | 持ち時間 |
| --- | --- | --- |
| SA / AA / AB / AC | 5セット(ワンセットダウン4セット) | 30分(25分) |
| BA / BB / BC | 4セット(ワンセットダウン3セット) | 25分(20分) |
| CA / CB / CC | 3セット(ワンセットダウン2セット) | 20分(15分) |
| Be | 2セット(ワンセットダウン2セット) | 15分(15分) |

- **前回優勝者**: 必要セット数が+1されます(全大会・全試合に適用。5→6セットの場合は持ち時間35分)
- **セカンダリハンデ**: 同じ頭文字のクラス内(例: AA/AB/AC同士、BA/BB/BC同士)で2文字目の差を比較し、クラスが低い方にブレイク権を付与します。差が2以上の場合は、さらにクラスが高い方の持ち時間を5分短縮します(例: AA対AC → ACにブレイク権、AAの持ち時間-5分)。**SA vs SA 以外の対戦では、SA側の持ち時間が5分短縮されます**(SA同士は通常時間)。Beのセカンダリハンデ判定はBBと同等に扱います
- **ワンセットダウン**: ダブルエリミネーションの敗者復活ブロックの対戦では、基本セット数より1セット少ない「ワンセットダウン」の数値を使用します。大会作成時(予選: ダブルエリミネーションを選んだ場合)に採用するかどうかを選択でき、デフォルトで採用されます
- **敗者復活ブロックのクロスオーバー方式**: ダブルエリミネーションの敗者復活ブロックでは、敗者復活勝ち残り選手と勝者側から新たに降格してきた選手を1対1で組み合わせる「クロスオーバー方式」で対戦を決定します(同じ出身側同士がすぐに再戦しないよう組み合わせます)
- スコア欄自体は記録用として従来通り自由入力です(セット数に達したら自動的に勝者が確定する、という仕様にはなっていません)

クラスごとの基本セット数・ワンセットダウンの数値は「設定」→「セット数」タブから編集できます(持ち時間はセット数から自動計算されるため直接編集はできません)。クラス区分・勝敗ポイント表もクラス「Be」を含めて「設定」タブから編集できます。

## 特別加点・減点(初期値)

| 条件 | 点数 |
| --- | --- |
| 決勝トーナメント進出 | +1 |
| 準優勝 | +1(Bクラス以下 +2) |
| 優勝 | +2(Bクラス以下 +4) |
| 決勝進出者中ベストBクラス | +2 |
| 決勝進出者中ベストCクラス | +2 |
| 前回優勝者に勝利 | +1 |
| 予選2敗による敗退 | -3 |

いずれも「設定」タブから変更できます。

**ポイント変動の下限**: 1つの大会の中で、敗北や予選敗退などによりポイントが減る場合、その大会での合計の点数変動(勝敗の合算)が初期値では-3を下回らないように自動的に制限されます(勝利・ボーナスによる加点には影響しません。大会をまたいだ選手の生涯合計ポイントそのものには制限はありません)。この下限値も「設定」→「ボーナス設定」タブから変更できます。

## データの保存について

入力したデータは各端末のブラウザ(localStorage)に保存されるのに加えて、Vercel Blob 上の共有データにも自動的に同期されます(ログイン不要、URLを知っている人は誰でも同じデータを見て編集できます)。画面左下に同期状況が表示されます(☁ クラウドに同期済み / 🔄 同期中 / ⚠ 同期エラー・📴 オフライン)。エラー・オフライン表示のときはその端末にのみ保存されており、次回オンライン時に自動で同期されます。複数端末でほぼ同時に編集した場合は、最後に保存した内容が優先されます(リアルタイムの共同編集・競合解決には対応していません)。別環境へデータを移したい場合は、「設定」タブの「データ管理」から JSON ファイルを書き出して読み込んでください。
