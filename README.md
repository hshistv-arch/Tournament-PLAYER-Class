# PLAYER-Class

ビリヤード大会のクラスポイントを管理するツールです。勝敗マトリクス（クラス差に応じたポイント増減表）に基づいて、試合結果からクラスポイントを自動計算・更新します。

## 使い方

`index.html` をブラウザで開くだけで動作します（サーバー不要）。GitHub Pages で公開する場合は、リポジトリの Settings → Pages でブランチを `main` / フォルダを `/ (root)` に設定してください。

## 主な機能

- **試合結果入力**: 勝者・敗者を選ぶとクラス差に応じたポイント変動をプレビューしてから記録
- **ランキング**: 全選手のクラスポイント順一覧、選手の追加・編集・削除
- **大会ボーナス**: 決勝トーナメント進出・優勝・ベストB/Cクラスのボーナス点を一括適用
- **履歴**: 試合・ボーナスの記録を個別に取り消し可能
- **設定**: クラス区分の点数範囲、勝敗ポイント表（勝利時／敗北時）、ボーナス点数をすべて編集可能
- **データ管理**: JSONファイルへのエクスポート／インポートで端末間のデータ共有が可能

## クラス区分（初期値）

| クラス | 範囲 |
| --- | --- |
| SA | 100以上 |
| AA | 90〜99 |
| AB | 80〜89 |
| AC | 70〜79 |
| BA | 60〜69 |
| BB | 50〜59 |
| BC | 40〜49 |
| CA | 30〜39 |
| CB | 20〜29 |
| CC | 19以下 |

※ ボーナス点数（決勝進出 +1 / 優勝 +2 / ベストB・Cクラス +2）とクラス区分・勝敗ポイント表は、いずれもアプリの「設定」タブから変更できます。

## データの保存について

入力したデータはブラウザの localStorage に保存されます。別の端末やブラウザと共有したい場合は、「設定」タブの「エクスポート（JSON）」でファイルを書き出し、共有先で「インポート（JSON）」から読み込んでください。
