# Tournament PLAYER-Class

ビリヤード大会のクラスポイントを管理するツールです。勝敗ポイント表（クラスの組み合わせごとに勝者が得る点・敗者が失う点を定めた表）に基づいて、試合結果からクラスポイントを自動計算・更新します。

## 使い方

`index.html` をブラウザで開くだけで動作します（サーバー不要）。GitHub Pages で公開する場合は、リポジトリの Settings → Pages でブランチを `main` / フォルダを `/ (root)` に設定してください。

## 主な機能

- **選手ロースター**: 選手の追加、氏名・ポイントの編集、削除。クラス(SA〜CC)はポイントから自動判定
- **大会作成**: 「リーグ戦(総当たり)」または「トーナメント戦(予選ブロック+決勝トーナメント)」を選択し、参加人数・参加者・予選ブロック数を指定して作成
- **試合結果入力**: 勝者を選ぶだけでクラス組み合わせに応じたポイントが自動加減算。入力ミス時は個別に取消が可能
- **予選ブロック**: 総当たりの中で2敗した選手は自動的に予選敗退となり、ペナルティ点を適用
- **決勝トーナメント**: シングルエリミネーション方式のブラケットを自動生成。優勝・準優勝が決まると、進出ボーナス・優勝ボーナス・ベストB/Cクラスボーナス・前回優勝者撃破ボーナスなどを自動計算して選手ポイントに反映し、次回大会用に優勝者を記録
- **設定**: クラス区分の点数範囲、勝敗ポイント表(勝利時／敗北時)、各種ボーナス点数をすべて編集可能(デフォルトに戻すボタンあり)
- **データ管理**: JSONファイルへのエクスポート／インポートで端末間のデータ共有が可能

## クラス区分(初期値)

| クラス | 範囲 |
| --- | --- |
| SA | 100以上 |
| AA | 90〜99 |
| AB | 80〜89 |
| AC | 70〜79 |
| BA | 60〜69 |
| BB | 50〜59 |
| BC | 40〜49 |
| CA | 30〜39 |
| CB | 20〜29 |
| CC | 10〜19 |

## 特別加点・減点(初期値)

| 条件 | 点数 |
| --- | --- |
| 決勝トーナメント進出 | +1 |
| 準優勝 | +1(Bクラス以下 +2) |
| 優勝 | +2(Bクラス以下 +4) |
| 決勝進出者中ベストBクラス | +2 |
| 決勝進出者中ベストB/Cクラス | +2 |
| 前回優勝者に勝利 | +1 |
| 予選2敗による敗退 | -3 |

いずれも「設定」タブから変更できます。

## データの保存について

入力したデータはブラウザの localStorage に保存されます。別の端末やブラウザと共有したい場合は、「設定」タブの「データ管理」から JSON ファイルを書き出し、共有先で読み込んでください(複数端末でのリアルタイム同時編集には対応していません)。
