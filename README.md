# Tournament PLAYER-Class

ビリヤード大会のクラスポイントを管理するツールです。勝敗ポイント表（クラスの組み合わせごとに勝者が得る点・敗者が失う点を定めた表）に基づいて、試合結果からクラスポイントを自動計算・更新します。

## 使い方

https://tournament-player-class.vercel.app を開くだけで使えます。ログイン不要で、このURLを知っている人は誰でも同じデータ(選手ロースター・大会結果など)を見て編集できる「共有ノート」のような仕組みです。`index.html` をファイルとして直接ブラウザで開くこともできますが、その場合は後述のクラウド同期は行われず、その端末のみに保存されます。スマートフォンでは「ホーム画面に追加」でアプリのように起動でき、アイコンには優勝カップのイラストを使用しています。

## 主な機能

- **選手ロースター**: 選手の追加、氏名・読みカナ・ポイントをその場で編集、削除。クラス(SA〜CC)はポイントから自動判定。一覧は「ポイント順」「名前順」「登録順」を切り替えて表示可能(名前順は読みカナがあればそれを、なければ氏名を使用。登録順はロースターに追加した順番)。ポイント欄の左には、その選手が参加した直近の完了済み大会より前の「前回ポイント」も参考表示されます。選手一覧はCSVファイルとして書き出し可能(表示中の並び順で出力)、または「サマリーを印刷」から氏名・クラス・最新ポイントのみの印刷用一覧(名前順)を表示して印刷できます。進行中(未完了)の大会に出場している選手は、その大会が完了するまでロースター上もエントリー時のポイント・クラスのまま表示されます(「大会中」の表示付き)。大会が完了すると自動的に最新のポイントに切り替わります
- **エントリー受付**: 大会作成前に、出場選手のエントリーと参加費受領を選手ごとにチェック。一覧は「名前順」「登録順」を切り替えて表示可能。この画面からロースター未登録の新規メンバーをその場で追加することもでき、その場合はポイントを直接入力する代わりにクラス(SA〜Be)を選ぶだけで登録できます(選んだクラスの下限ポイントで登録され、追加と同時にエントリー済みの状態になります)。大会作成後の組み合わせ選択は、ここでエントリー・受領済みの選手が対象になります(未設定の場合はロースター全員が対象)
- **大会作成**: 大会名を入力したら、まず「出場選手を選択」欄でエントリー・参加費受領済みの選手一覧(名前順)からチェックボックスで出場者を選びます(デフォルトで全員チェック済み・欠席者はチェックを外すだけ。チェック済みの選手は行がグレー表示され、スクロールしても一目で判別できます)。「エントリー受付でチェック済みの選手のみ表示する」のチェックを外すと、ロースター全員が選択対象になります。総参加人数はチェック数から自動設定され、続けて試合形式を選ぶだけで完了です。「ポイント・セット数を使用する」のチェックを外すと(デフォルトはチェック済み=使用する)、その大会では勝敗の記録だけを行い、クラスポイントの加減算・優勝ボーナスなどを一切行わない「勝敗記録のみ」の大会として運用できます(親善試合・イベント戦などクラスポイントに影響させたくない大会向け)。この場合、選手のクラスはポイントから自動判定されなくなりますが、「出場選手を選択」でチェックした選手ごとに、P/SA/A/B/C/Beの中から任意でクラスを手入力できます(未入力の選手はクラス表示なしのまま)。大会作成後も、各ブロック/グループの「出場選手を編集」欄で同様にいつでもクラスを設定・変更できます。入力したクラスは対戦カードや順位表・印刷ページ・観戦用ディスプレイにバッジとして表示され、そのクラスに応じたセット数・持ち時間も対戦カードに表示されます(クラスごとのセット数は「設定」→「セット数」タブの専用表で編集可能。ポイント使用時と同様「セット数A」「セット数B」の2種類があり、大会作成画面または大会画面上部の「基本セット数」でどちらを使うか選べます。デフォルト値: セット数AはP=6セット・SA=5セット・A=5セット・B=4セット・C=3セット・Be=2セット、セット数BはP=6セット・SA=6セット・A=6セット・B=5セット・C=4セット・Be=4セット)。PクラスとSAクラスの対戦では、P側のセット数が1セット少ない「1セットダウン」扱いになります(SA側は通常通り)。ただし、これらはあくまで進行の目安であり、ポイント計算やクラスポイントには一切影響しません
  - **①トーナメント戦(予選+決勝)**: 予選をノックアウト方式で行い、予選グループ数・各グループからの決勝進出人数を指定。指定人数まで絞り込まれたら決勝トーナメントへ。予選方式は次の3つから選択できます
    - **シングルエリミネーション**: 1敗で失格
    - **ダブルエリミネーション**: 2敗で失格。1敗した選手は敗者復活ブロックに回り、何度でも(2敗するまで)勝ち上がりを狙えます
    - **1回戦のみダブルエリミネーション**: 1回戦で敗れた選手だけが敗者復活ブロックで1度だけ再挑戦でき、そこで勝てば勝ち残り・負ければ失格。2回戦以降の敗者は1敗で失格となります(敗者復活ブロックは1回戦のみで、それ以降は作られません)
  - **②予選リーグ戦(ブロック総当たり)+決勝トーナメント**: 参加者をブロックに分けて総当たり戦を行い、各ブロック上位が決勝トーナメントに進出(ブロック内で2敗した選手は自動的に予選敗退)。予選ブロック数はデフォルト3。決勝進出のボーダーラインで勝敗数が同数の選手がいる場合は(ポイントが異なっていても)、自動判定せずどちらが進出するかを手動で選択できます
- **大会作成時に出場選手を自動割当**: 「出場選手を選択」でチェックした選手は、大会作成と同時にポイント順のシードで各グループ/ブロックの枠へ自動的に割り当てられます(グループが複数ある場合は上位選手が均等に分散されます)。作成後も「出場選手を編集」欄のプルダウンでいつでも組み替え可能です(同じ組み合わせ内の他の枠に既に割り当て済みの選手は、プルダウンの選択肢一覧でグレー表示・「✓選択済み」の表記が付き、スクロールしても一目で判別できます)(「組み合わせを確定」で大会を開始。未割当の枠は不戦/空きとして扱われます)。出場選手は決勝トーナメント開始後・大会終了後でも入れ替え可能で、変更すると該当ブロック/グループの結果と決勝トーナメントの結果が自動的に巻き戻されて再構築されます。決勝トーナメントの枠(空の「(不戦)」表示)も、予選が確定する前から進出予定人数分だけ先に表示されます
- **開始後の人数・決勝進出人数の変更**: 各ブロック/グループの人数と、各ブロック/グループからの決勝進出人数は、大会開始後・決勝トーナメント開始後でもいつでも変更可能です(変更すると該当ブラケット・決勝トーナメントの結果が必要に応じて巻き戻されます)。ダブルエリミネーションの場合、決勝進出人数は勝者側・敗者側それぞれ何名ずつ選出するかを個別に指定できます(各グループの現在の勝ち残り上位からポイント順に選出)
- **大会作成後の形式変更**: 大会画面上部の「大会形式」から、①トーナメント戦(予選+決勝)と②予選リーグ戦+決勝トーナメントをいつでも切り替えられます。切り替えるとその大会の対戦結果・組み合わせはすべてリセットされ、加減算されたポイントも元に戻った上で「組み合わせ待ち」からやり直しになります(出場選手の顔ぶれは維持されたまま、新しい形式の組み合わせに自動で割り当て直されます)。同じ場所の「ポイント・セット数を使用する」チェックボックスで、大会作成後もポイント・セット数を使う/使わないをいつでも切り替えられます(出場選手の組み合わせ・人数はそのまま維持され、その大会の対戦結果のみリセットされます)。①トーナメント戦の場合は「予選グループ数」もここでいつでも変更でき、変更すると出場選手が現在のポイント順で新しいグループ数に自動で再割当されます(対戦結果はリセットされ、「組み合わせ待ち」から再度組み合わせを確認・確定します)
- **トーナメント表ビジュアル**: 決勝トーナメントおよび予選のシングル/ダブルエリミネーションを、対戦カードを線でつないだブラケット表示で見える化(対戦Noを表示。ダブルエリミネーションの敗者復活ブロックは別枠でリスト表示)。予選開始直後などまだ結果が出ていないラウンドも「(未定)」の空き枠として先に表示され、トーナメント表全体の形が常に見えるようになっています。予選の勝者側ブラケットは、設定した決勝進出人数まで絞り込むのに必要なラウンド数までしか表示されません(例: 8名中4名が決勝進出なら1回戦のみ、2名なら2回戦まで)。実際にはプレイされない先のラウンドの枠は表示されません
- **試合結果入力・スコア記録**: 勝者を選ぶだけでクラス組み合わせに応じたポイントが自動加減算。対戦スコアは選手名の横にやや大きめの文字で記録可能(ポイント計算には影響しない参考記録)。勝者を選ぶと、その時点でスコアの数字に関わらず勝者側のスコア欄が赤字の「W」表示に切り替わり、一目で勝者がわかります(敗者側のスコアはそのまま数字で表示されます)。この表示は入力画面だけでなく、別画面表示・印刷画面でも同様に反映されます。結果は決勝トーナメント開始後・大会終了後でもいつでも取消・修正でき、後続の組み合わせ結果や決勝トーナメントの結果が既にある場合は自動的に巻き戻して再計算します
- **決勝トーナメント**: 優勝・準優勝が決まると、進出ボーナス・優勝ボーナス・ベストB/Cクラスボーナス・前回優勝者撃破ボーナスなどを自動計算して選手ポイントに反映し、次回大会用に優勝者を記録。決勝トーナメントの組み合わせは「ランダムに再抽選」または「決勝進出者の中から任意で組み合わせを選んで編集」のどちらでも変更可能です(進行中の対戦結果・大会結果があれば取り消してから組み直します)。「決勝の組み合わせを選んで編集」欄は予選の組み合わせ編集欄と同様、最初から展開された状態で表示されます
- **大会終了時のポイント変化一覧**: 大会が終了すると、優勝・準優勝のボーナスログに加えて、その大会に参加した全選手の合計ポイント変動(対戦の勝敗・ボーナス・ペナルティをすべて合算、下限ポイントのルールも適用済み)を一覧表示します(クラスはエントリー時のもの。最新の合計ポイントは選手ロースター側でご確認ください)。「大会結果を印刷する」から、優勝・準優勝・ボーナス内訳(氏名・内容のみ、ポイント数は非表示)・予選の結果(①はトーナメント表、②は各ブロックの順位表と対戦結果)・決勝トーナメント表を印刷用にまとめて表示・印刷できます。「ポイント・セット数を使用する」を外した大会では、ボーナス内訳は表示されず(発生しないため)、予選・決勝ともポイントの表示は省略されます(クラスとセット数は、手入力した選手のみ表示されます)
- **別画面への表示(観戦用ディスプレイ)**: 大会画面や大会一覧の「別画面に表示」から、その大会の進行状況(組み合わせ・対戦結果・順位表・決勝トーナメント表)を、編集操作のできない大きな文字の閲覧専用画面として別タブ/別ウインドウで開けます。画面上部には大会名とあわせて大会方式(①トーナメント戦の場合は予選方式まで/②予選リーグ戦)と進行状況が表示され、大会IDなしで開いたときの大会選択一覧にも各大会の方式が併記されます。プロジェクターや別モニターに映してお客様に見せる用途を想定しており、約6秒ごとに自動でデータを再取得して表示を更新します(操作する端末とは別の端末・タブで開いても、共有クラウド同期を通じて同じ内容が表示されます)。URLに`?display=1`(大会IDなしなら大会選択一覧、`&id=大会ID`を付けるとその大会を直接表示)を付けることでも開けます。同じ場所の「QRコードを表示」からその画面へのQRコードも作成でき、スマートフォンやタブレットで読み取ってすぐ観戦用ディスプレイを開けます。大会が終了すると、この観戦用ディスプレイにだけ控えめな祝福の花火演出が数秒間表示されます。画面右上の「✕ 閉じる」ボタンから、そのタブ/ウインドウを閉じられます(スマートフォンなどでブラウザの閉じるボタンが見つかりにくい場合にご利用ください)
- **対戦ごとのセット数・持ち時間**: 対戦カードに、両選手それぞれの必要セット数とチェスクロックの持ち時間を自動表示します(下記「対戦ルール」参照)。組み合わせが決まっている対戦であれば、予選・決勝を問わず表示されます
- **設定**: クラス区分の点数範囲、勝敗ポイント表(勝利時／敗北時)、各種ボーナス点数をすべて編集可能(デフォルトに戻すボタンあり)
- **データ管理**: JSONファイルへのエクスポート／インポートで端末間のデータ共有が可能
- **大会の削除**: 大会一覧から削除すると、その大会で加減算されたポイントがすべて元に戻ります。誤って削除しないよう、大会一覧または大会画面の「🔒 削除をロック」から個別の大会をロックでき、ロック中は削除ボタン自体が表示されず削除できません(「🔓 ロック解除」でいつでも解除可能)

## 対戦ルール(セット数・持ち時間・セカンダリハンデ)

各対戦カードには、両選手それぞれの必要セット数とチェスクロックの持ち時間が自動表示されます。

基本セット数の表は「セット数A」「セット数B」の2種類を用意しており、**どちらを使うかは大会ごとに選択します(デフォルトはセット数A)**。大会作成画面の「基本セット数」で選ぶほか、大会画面の上部からいつでも切り替えられます(切り替えても対戦結果やポイントには影響せず、表示されるセット数・持ち時間だけが変わります)。両方の表の数値は「設定」→「セット数」タブでクラスごとに編集でき、表ごとに個別のデフォルトへ戻せます。

**セット数A(デフォルト)**

| クラス | セット数 | 持ち時間 |
| --- | --- | --- |
| SA / AA / AB / AC | 5セット(ワンセットダウン4セット) | 30分(25分) |
| BA / BB / BC | 4セット(ワンセットダウン3セット) | 25分(20分) |
| CA / CB / CC | 3セット(ワンセットダウン2セット) | 20分(15分) |
| Be | 2セット(ワンセットダウン2セット) | 15分(15分) |

**セット数B**

| クラス | セット数 | 持ち時間 |
| --- | --- | --- |
| SA / AA / AB / AC | 6セット(ワンセットダウン5セット) | 35分(30分) |
| BA / BB / BC | 5セット(ワンセットダウン4セット) | 30分(25分) |
| CA / CB / CC | 4セット(ワンセットダウン3セット) | 25分(20分) |
| Be | 4セット(ワンセットダウン3セット) | 25分(20分) |

- **前回優勝者**: 必要セット数が+1されます(全大会・全試合に適用。5→6セットの場合は持ち時間35分)
- **セカンダリハンデ**: 同じ頭文字のクラス内(例: AA/AB/AC同士、BA/BB/BC同士)で2文字目の差を比較し、クラスが低い方にブレイク権を付与します。差が2以上の場合は、さらにクラスが高い方の持ち時間を5分短縮します(例: AA対AC → ACにブレイク権、AAの持ち時間-5分)。**SA vs SA 以外の対戦では、SA側の持ち時間が5分短縮されます**(SA同士は通常時間)。Beのセカンダリハンデ判定はBBと同等に扱います
- **ワンセットダウン**: ダブルエリミネーションの敗者復活ブロックの対戦では、基本セット数より1セット少ない「ワンセットダウン」の数値を使用します。大会作成時(予選: ダブルエリミネーションを選んだ場合)に採用するかどうかを選択でき、デフォルトで採用されます
- **敗者復活ブロックのクロスオーバー方式**: ダブルエリミネーションの敗者復活ブロックでは、敗者復活勝ち残り選手と勝者側から新たに降格してきた選手を1対1で組み合わせる「クロスオーバー方式」で対戦を決定します(同じ出身側同士がすぐに再戦しないよう組み合わせます)
- **エントリー時の状態で計算・表示**: 大会(組み合わせを確定して開始した時点)ごとに、参加者全員のポイントと、その時点の前回優勝者(前回優勝者ボーナス・セット数+1の対象)をスナップショットします。大会中の勝敗ポイント表・セット数・持ち時間・セカンダリハンデの計算、予選の順位付けや決勝進出者・優勝ボーナス階級(ベストB/Cクラスを含む)の判定、対戦カード上や大会結果に表示されるポイント・クラス・セット数は、すべてこのスナップショット時点の値を使用します。この値は大会が完了した後もそのまま保持され続け、他の対戦・他の大会でポイントや前回優勝者が変わっても、その大会自身の記録(対戦カード・順位表・大会結果・印刷用サマリー)には反映されません。実際のポイントの加減算自体は各対戦終了時に即座に選手ロースターに反映され、大会が完了すればロースターの表示も最新の値に切り替わります(ロースターと、完了済み大会自身の記録は別々に扱われます)。決勝トーナメント開始後に途中から出場する選手は、その時点のポイントがスナップショットされます
- スコア欄自体は記録用として従来通り自由入力です(セット数に達したら自動的に勝者が確定する、という仕様にはなっていません)

クラスごとの基本セット数・ワンセットダウンの数値は「設定」→「セット数」タブから編集できます(持ち時間はセット数から自動計算されるため直接編集はできません)。クラス区分・勝敗ポイント表もクラス「Be」を含めて「設定」タブから編集できます。同じ「セット数」タブには、「ポイント・セット数を使用しない」大会で使う、P/SA/A/B/C/Beクラスごとのセット数表も別途あり、こちらも編集可能です。ポイント使用時と同じく「セット数A」「セット数B」の2表があります(デフォルト: セット数AはP=6/SA=5/A=5/B=4/C=3/Be=2セット、セット数BはP=6/SA=6/A=6/B=5/C=4/Be=4セット)。PクラスとSAクラスの対戦は、P側が1セットダウン扱いになります。

| --- | --- |
| 決勝トーナメント進出 | +1 |
| 準優勝 | +1(Bクラス以下 +2) |

| 決勝進出者中ベストCクラス | +2 |
| 前回優勝者に勝利 | +1 |
| 予選2敗による敗退 | -3 |

いずれも「設定」タブから変更できます。

**ポイント変動の下限**: 1つの大会の中で、敗北や予選敗退などによりポイントが減る場合、その大会での合計の点数変動(勝敗の合算)が初期値では-3を下回らないように自動的に制限されます(勝利・ボーナスによる加点には影響しません。大会をまたいだ選手の生涯合計ポイントそのものには制限はありません)。この下限値も「設定」→「ボーナス設定」タブから変更できます。

## データの保存について

入力したデータは各端末のブラウザ(localStorage)に保存されるのに加えて、Vercel Blob 上の共有データにも自動的に同期されます(ログイン不要、URLを知っている人は誰でも同じデータを見て編集できます)。画面左下に同期状況が表示されます(☁ クラウドに同期済み / 🔄 同期中 / ⚠ 同期エラー・📴 オフライン)。エラー・オフライン表示のときはその端末にのみ保存されており、次回オンライン時に自動で同期されます。複数端末でほぼ同時に編集した場合は、最後に保存した内容が優先されます(リアルタイムの共同編集・競合解決には対応していません)。別環境へデータを移したい場合は、「設定」タブの「データ管理」から JSON ファイルを書き出して読み込んでください。
