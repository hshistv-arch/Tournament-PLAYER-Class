# Tournament PLAYER-Class

ビリヤード大会のクラスポイントを管理するツールです。勝敗ポイント表（クラスの組み合わせごとに勝者が得る点・敗者が失う点を定めた表）に基づいて、試合結果からクラスポイントを自動計算・更新します。

## 使い方

`index.html` をブラウザで開くだけで動作します（サーバー不要）。GitHub Pages で公開する場合は、リポジトリの Settings → Pages でブランチを `main` / フォルダを `/ (root)` に設定してください。

## 主な機能

- **選手ロースター**: 選手の追加、氏名・ポイントの編集、削除。クラス(SA〜CC)はポイントから自動判定
- **大会作成**: 大会作成時にはまず試合形式と参加人数だけを決めます
  - **①トーナメント戦(予選+決勝)**: 予選をシングルエリミネーション(1敗失格)またはダブルエリミネーション(2敗失格・敗者復活あり)のノックアウト方式で行い、予選グループ数・各グループからの決勝進出人数を指定。指定人数まで絞り込まれたら決勝トーナメントへ
  - **②予選リーグ戦(ブロック総当たり)+決勝トーナメント**: 参加者をブロックに分けて総当たり戦を行い、各ブロック上位が決勝トーナメントに進出(ブロック内で2敗した選手は自動的に予選敗退)
- **大会作成後に出場選手を選択**: 大会を作成すると、トーナメント表/ブロック表の各枠が空欄で生成されます。各枠のプルダウンからロースターの選手を選んで組み合わせを決め、「組み合わせを確定」で大会を開始します(未割当の枠は不戦/空きとして扱われます)
- **トーナメント表ビジュアル**: 決勝トーナメントおよび予選のシングル/ダブルエリミネーションを、対戦カードを線でつないだブラケット表示で見える化(ダブルエリミネーションの敗者復活ブロックは別枠でリスト表示)
- **試合結果入力**: 勝者を選ぶだけでクラス組み合わせに応じたポイントが自動加減算。入力ミス時は個別に取消が可能(ただし後続の組み合わせが確定した試合は取消不可)
- **決勝トーナメント**: 優勝・準優勝が決まると、進出ボーナス・優勝ボーナス・ベストB/Cクラスボーナス・前回優勝者撃破ボーナスなどを自動計算して選手ポイントに反映し、次回大会用に優勝者を記録
- **設定**: クラス区分の点数範囲、勝敗ポイント表(勝利時／敗北時)、各種ボーナス点数をすべて編集可能(デフォルトに戻すボタンあり)
- **データ管理**: JSONファイルへのエクスポート／インポートで端末間のデータ共有が可能

## クラス区分(初期値)

| クラス | 範囲 |
| --- | --- |
| SA | 100以上 |
| AA | 90〜99 |
| AB | 80〜89 |
| AC | 70〜79 |
| BA | 60〜69 |
| BB | 50〜59 |
| BC | 40〜49 |
| CA | 30〜39 |
| CB | 20〜29 |
| CC | 10〜19 |

## 特別加点・減点(初期値)

| 条件 | 点数 |
| --- | --- |
| 決勝トーナメント進出 | +1 |
| 準優勝 | +1(Bクラス以下 +2) |
| 優勝 | +2(Bクラス以下 +4) |
| 決勝進出者中ベストBクラス | +2 |
| 決勝進出者中ベストB/Cクラス | +2 |
| 前回優勝者に勝利 | +1 |
| 予選2敗による敗退 | -3 |

いずれも「設定」タブから変更できます。

## データの保存について

入力したデータはブラウザの localStorage に保存されます。別の端末やブラウザと共有したい場合は、「設定」タブの「データ管理」から JSON ファイルを書き出し、共有先で読み込んでください(複数端末でのリアルタイム同時編集には対応していません)。
